# receipt-ai
# 🧾 Recibo AI

Aplicação web desenvolvida durante a **Missão Programação com IA do Zero**, com o objetivo de facilitar a leitura e organização de informações presentes em notas fiscais e comprovantes.

## 🚀 Sobre o projeto

Este foi um dos meus primeiros projetos práticos na área de desenvolvimento web.

A aplicação permite selecionar uma imagem de um comprovante e utiliza Inteligência Artificial para analisar as informações presentes no documento, organizando os dados de forma estruturada.

Durante o desenvolvimento, além de aplicar os conceitos apresentados nas aulas, realizei algumas personalizações de interface e funcionamento para deixar o projeto mais próximo da minha própria visão.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS
- JavaScript
- Inteligência Artificial
- Visual Studio Code

## ✨ Funcionalidades

- 📷 Seleção de imagem de um comprovante
- 🤖 Análise utilizando Inteligência Artificial
- 🧾 Identificação de informações da nota
- 📦 Organização dos produtos
- 💰 Cálculo do valor total
- 💳 Identificação da forma de pagamento
- 📊 Contagem de comprovantes processados
